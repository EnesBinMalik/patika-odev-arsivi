# Güvenlik Politikası

## Bildirim

Güvenlik açığı bulursan **herkese açık issue açma**. Depo sahibine GitHub profili üzerinden özel mesaj
gönder veya GitHub'ın "Report a vulnerability" (Security → Advisories) akışını kullan.

## Kapsam

Bu depodaki ödevler eğitim amaçlıdır; üretim ortamı için tasarlanmamıştır. Yine de:

- Gömülü anahtar/parola bulursan bildir
- Bağımlılık kaynaklı açık varsa sürüm önerisiyle bildir

Yanıt süresi hedefi: 7 gün.
